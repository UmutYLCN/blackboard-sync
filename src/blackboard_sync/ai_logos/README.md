# AI tool logos

The buttons on Home's AI study session card. Each is the vendor's own mark, taken from a
product the vendor distributes and only rendered to a 128 px PNG (not redrawn or recolored).
The marks are trademarks of their owners; they are shown only to name the tool a button opens.
This project's license does not cover them.

| `codex.png` | OpenAI | `resources/blossom-black.svg` in the "Codex – OpenAI's coding agent" extension 26.1117 |

## Gemini Notebook

`gemini-notebook.png` is the mark beside the title of Home's notebook card: Gemini Notebook (Google),
formerly NotebookLM. It is cut out of a picture of Google's "Gemini Notebook" header with the dark
background made transparent, at the picture's own size (40 x 29), not redrawn or recolored. Replace it
with a larger official file when one is at hand. The same trademark note as above applies.
