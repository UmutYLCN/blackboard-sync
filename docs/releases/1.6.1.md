# Blackboard Sync 1.6.1

- Modernized Windows buttons, inputs, checkboxes and sidebar navigation with a shared visual theme.
- The Windows app selects a light or dark theme from your Windows app appearance preference at startup. Restart Blackboard Sync after changing that preference.
- Improved primary action buttons, selected navigation rows and disabled control states.
- Rounded action buttons now adapt to dark backgrounds, including hover, pressed and keyboard focus states.
- Updated documentation links to the official website and privacy policy at **blackboardsyncapp.com**.

Windows and macOS packages include the existing Google Calendar integration and the current past-term download controls from version 1.6.0.
