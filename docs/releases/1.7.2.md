# Blackboard Sync 1.7.2

- **Free desktop Store editions.** Windows is available through the Microsoft Store, and macOS has a sandboxed Mac App Store edition with in-app Blackboard sign-in, persistent access to the folder you choose, and a demo you can try without signing in.
- **Updates for existing Mac installs.** The GitHub download is the final direct `.dmg`. It adds the minimum-version check and can direct you to the Mac App Store when direct downloads are retired. Store editions receive updates through their respective stores.
- **Find your university and use the app in more languages.** The school picker suggests matches as you type and includes 193 verified schools. Spanish, French, German, and right-to-left Arabic join English and Turkish.
- **Study tools on Home.** Start an AI study session in your term folder from Home or the menu bar or tray. Choose your AI tool, including Antigravity CLI, and see NotebookLM under its new name, Gemini Notebook.
- **Easier to scan.** Colored course codes identify recent downloads, announcements, and calendar events. The desktop window uses a fixed size with scrolling content, and courses without a term start disabled.
- **More reliable sign-in and downloads.** Re-signing in clears old tabs in the sign-in browser profile. File downloads can resume when the server supports it, preserve modification times when available, and distinguish missing files from temporary download errors.
