# Blackboard Sync 1.6.0

- Optional Google Calendar deadline sync into a dedicated **Blackboard Deadlines** calendar.
- Connect, sync and disconnect in macOS Settings; CLI connection controls and automatic updates in Windows.
- Calendar updates run after successful app syncs and respect Pause. Hidden courses are removed from Google; enabling them again restores eligible deadlines.
- Compact Calendar settings, readable local sync times, cancellation and reconnect attention messages.
- Google client configuration is included in official packages, so end users do not need terminal setup.
- Disconnect can preserve the calendar or explicitly delete it, including after reconnecting.
- Past-term downloads in the desktop apps are temporarily disabled and marked **Coming soon** while that workflow is redesigned. Existing downloaded files are kept.
- Updated privacy disclosures, Google Limited Use statement and setup documentation.

Google Calendar is optional and uses only the `calendar.app.created` scope. The
app does not access personal events or write to your main calendar. Google
authorization availability depends on the OAuth application's publishing and
verification status; Testing projects accept only approved test users.
